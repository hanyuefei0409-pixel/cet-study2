# CET学习舱 - 原界面修复升级

本包以 `https://hanyuefei0409-pixel.github.io/cet-study2/` 当前线上版本为基础修改，保留原来的蓝色手机端界面和词汇学习方式。

## 更新现有仓库

1. 先备份本地 `cet-study2` 仓库。
2. 解压本包，将里面全部文件复制到原仓库根目录，同名文件选择覆盖，文件夹选择合并。
3. 确认仓库根目录有 `index.html`、`exam-data.js`，并有完整的 `resources/cet4/`。
4. GitHub Desktop 中填写说明，例如“修复错题、阅读下一题并接入真题听力”。
5. 点击 Commit to main，再点击 Push origin。
6. 等待 GitHub Pages 更新后重新打开网站。

## 手机清理旧缓存

如果更新后仍显示旧版：

- iPhone/iPad：删除旧桌面图标，在“设置 → Safari → 高级 → 网站数据”中删除该 GitHub Pages 网站数据，再用 Safari 打开并重新添加到主屏幕。
- Android：Chrome 打开网站设置，执行“清除并重置”，重新打开后再安装到桌面。

## 安装为免费应用

- iPhone/iPad：Safari → 分享 → 添加到主屏幕。
- Android：Chrome/Edge → 菜单 → 安装应用或添加到主屏幕。

这是 PWA，不需要应用商店费用。微信小程序需要单独改写和审核，建议先使用 PWA。
